# Notice and third-party acknowledgements

Parlure is a local iOS application for capturing, reviewing, redacting, and exporting Québec French speech/dialogue data for downstream governance pipelines.

## Apple platform technologies

Parlure uses Apple platform APIs and frameworks where available, including SwiftUI, SwiftData, Speech, AVFoundation, OSLog, and optional FoundationModels support. Use of these APIs does not imply Apple endorsement.

## Connected project

Parlure exports review-gated data intended to be imported by `ales27pm/Quec-fr-CA-llm-training-`.

## Data and consent notice

Parlure-generated exports may contain user-provided speech, text, local clarifications, redacted text, metadata, and synthetic assistant responses. Exported data is not automatically licensed for public release, commercial model training, or redistribution. Each record must be reviewed according to its consent, review, PII, and provenance fields.
